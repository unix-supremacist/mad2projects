In November 2019, me and my friend ‪@ImJustATester‬ were trying to figure out the cheat combinations of Madagascar 2. While messing with the game, he managed to access the "Debug Options"; he uploaded a video showcasing it here:    • [PS2] Madagascar: Escape 2 Africa - Debug ...
But the cheat combinations were still unknown, and only 3 of them were online ("Infinite Sprint", "Minigolf - Ball Stop" and "Invulnerability - Alex" from this german site https://www.mogelpower.de/cheats/Mada... ).
On the 23rd of July 2023, I discovered the combinations of the remaining cheat codes.
I'm specifically playing on the PS2 version, NTSC. The codes have also been tried on the Wii and PC versions, which include some differences from the PS2 release (listed below).

There're 18 cheat codes in total, but some of them don't have any sequence (the input values are filled with 0xFFFFFFFF, but manually creating the sequence will make them inputtable, as shown in the video). Only for the PS2 and Wii version the "Unlock Levels" cheat code has a sequence, and only for the Wii and PC version the "Giant Frogs" cheat code has a sequence.

Technical:
NOTE: The addresses change every time the Cheats menu is accessed. I couldn't find any pointers that worked to always get to this region.

A cheat code sequence is composed of 8 inputs, and for each sequence the game stores 8 pointers to the 8 inputs' structs.
https://i.gyazo.com/232a0edfe6c4de947...

Each input struct is composed of 0x38 bytes, in which the field at +0x24 is the ID of an input (0 to 10 from the list above).
The pointers are ordered in a forward-manner, but the structs are one before the other, so they go in "reverse".
For example, the Infinite Sprint cheat code is "8 8 3 3 0 3 0 3", and this is how its sequence is stored in memory:
https://cdn.discordapp.com/attachment...

A locked cheat has a value of 0, a disabled cheat has a value of 1 and an enabled cheat has a value of 2.
